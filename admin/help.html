怎么用内容后台

完整说明见仓库《怎么用后台.md》。下面是最短路径。

日常三步

打开 /admin/ → 用 GitHub 登录 → 改项目并发布。
约两三分钟后前台更新。

第一次

  1. 在 GitHub 创建 OAuth App，回调填 https://axellab.org/api/callback
  2. 把 Client ID / Secret 配进 Cloudflare Secrets
  3. 用有仓库写权限的 GitHub 账号登录

改图

项目图放在该项目的 images/ 下，图库里填文件名；封面字段填如 cover.jpg。
