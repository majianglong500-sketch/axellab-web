把图直接丢进本文件夹，文件名按下面约定（覆盖同名 = 换图）：

  cover.jpg          ← 封面 / 列表缩略图 / 详情页主图（必填）
  gallery-01.jpg     ← 图库第 1 张（推荐命名）
  gallery-02.jpg     ← 图库第 2 张
  gallery-03.jpg     ← …
  video.mp4          ← 可选短片

也可继续用 01.jpg、02.jpg…，但必须和上一级 文案.md →「## 图库」里的 file: 一致。

换封面：覆盖 cover.jpg，然后到仓库根目录运行：
  python build.py
  git add -A && git commit -m "content: update cover" && git push origin main

建议：封面宽边 ≥ 1200px；图库单张大约 200–500KB。
